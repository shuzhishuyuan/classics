# Login artwork

The student, books, and scroll PNGs are Microsoft Fluent Emoji 3D assets,
used under the MIT license. The original license is included in `LICENSE`.

Source: https://github.com/microsoft/fluentui-emoji

- `student-boy.png`: `assets/Man student/Light/3D/man_student_3d_light.png`
- `student-girl.png`: `assets/Woman student/Light/3D/woman_student_3d_light.png`
- `books.png`: `assets/Books/3D/books_3d.png`
- `scroll.png`: `assets/Scroll/3D/scroll_3d.png`

Animations are provided locally in `src/pages/homePage.css`; the page does
not fetch artwork from external services at runtime.
